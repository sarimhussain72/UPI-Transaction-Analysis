# 💳 UPI Transaction Analysis Dashboard

## 📌 Project Overview

This project analyses UPI (Unified Payments Interface) transaction data using **MySQL** and **Power BI** 
to uncover transaction trends, payment behaviour, fraud patterns, and banking performance. The dashboard 
provides interactive visualizations and key performance indicators (KPIs) that help stakeholders monitor digital payment activity and make data-driven decisions.

---

## 🎯 Objectives

* Analyse transaction volume and transaction amount.
* Measure transaction success and failure rates.
* Identify suspected fraudulent transactions.
* Evaluate bank-wise and state-wise transaction performance.
* Analyse transaction trends by hour, day, and month.
* Monitor cashback distribution and payment methods.
* Build an interactive dashboard for business insights.

---

## 🛠️ Tools & Technologies

* **MySQL Workbench** – Data querying and analysis
